# HomeCore Labs

Experiment area on the HomeCore demo, https://mbb365.github.io/homecore-labs/


SEPARATE from the main demo (https://mbb365.github.io/homecore-demo/, repo mbb365/homecore-demo). Nothing here changes that demo; an experiment moves over only once it's agreed.


## What's in it

- **Areas lab** [(in the rail, under Dashboards)](https://mbb365.github.io/homecore-labs/#/areas): four ways to show every area: One card · compact, One card · full, Accordion and Area cards. In Edit, drag any side or corner to resize; cards snap to the grid and pack from the top left. Its layout is saved apart from Dashboards.

Everything else is the HomeCore demo as it was when Labs was made.
