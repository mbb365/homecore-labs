# HomeCore Labs

Experiments on the HomeCore demo, kept apart from the demo for leadership (https://mbb365.github.io/homecore-demo/, repo mbb365/homecore-demo). Nothing here changes that demo; an experiment moves over only once it's agreed.

Private: only people invited to this repo can see it.

## Run it

```
npm install
npm run dev
```

It opens at http://localhost:5240.

## What's in it

- **Areas lab** (in the rail, under Dashboards): four ways to show every area: One card · compact, One card · full, Accordion and Area cards. In Edit, drag any side or corner to resize; cards snap to the grid and pack from the top left. Its layout is saved apart from Dashboards.

Everything else is the HomeCore demo as it was when Labs was made.
